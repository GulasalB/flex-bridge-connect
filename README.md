# FLEX Bridge Connect


Custom Onboarding/Sign-Up: A registration flow capturing FLEX year, host country, and host state. Include optional fields for contact information (email) and social media links.

Opportunities Board: A feed where Administrators (City Representatives) can post upcoming events, workshops, and alumni opportunities. Users should be able to view and RSVP.

Discussion Board: A community forum where alumni can post questions, share advice, and reply to threads regarding university applications, reverse culture shock, and career planning.

Matching Interface: A visual dashboard that connects mentees with suitable mentors based on goals (e.g., US college applications, career advice, transition support).

Mentorship Workspace: A private scheduling and goal-tracking area where matched pairs can log their 1-on-1 session progress.

Admin Panel: A dashboard for City Representatives to monitor engagement, view active mentorship pairs, and track total session hours.
